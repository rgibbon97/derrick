HOW THE POSITION-BASED VOLUME MODEL WORKS

Most drilling fluid spreadsheets are static — a snapshot of the well with the BHA on bottom at TD. The moment you trip, drill ahead, or circulate off bottom, the manually entered pipe lengths per section are wrong and someone has to re-split them by hand. This calculator removes that step: string position is driven entirely by Current Bit Depth and Current Hole Depth, and every other length is derived automatically.

THE OVERLAP METHOD

Each string component's Bottom MD and Top MD are computed by chaining lengths upward from the bit — the bottommost component's Bottom MD equals Current Bit Depth, and each component's Top MD is its own Bottom MD minus its length, which becomes the Bottom MD of the component above it. Well sections (casing, liner, open hole) chain the same way from surface down, with the last section's Bottom MD tied to Current Hole Depth.

For every component × well-section pair, the length of that component actually inside that section is:

Overlap = MAX(0, MIN(Component Bottom, Section Bottom) − MAX(Component Top, Section Top))

Summed across all pairs, this automatically redistributes pipe between casing, liner and open hole as the bit moves — no manual interval lengths, ever.

DRILLING, TRIPPING AND CIRCULATING

  • Drilling ahead: update Bit Depth and Hole Depth together as you drill down.
  • Tripping out: update Bit Depth only — Hole Depth stays fixed at the last drilled TD. Components above surface simply stop contributing volume.
  • Running in hole: update Bit Depth only, up to the fixed Hole Depth.
  • Backreaming / circulating off bottom: set Bit Depth to the pipe's actual position; Hole Depth stays fixed.
